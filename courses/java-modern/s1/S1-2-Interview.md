# Java 17 LTS：语言结构现代化 · 面试追问

> 17 是当下主流生产版本，record/sealed/模式匹配几乎是"现代 Java"面试必问。高分点：不止会说语法，而是讲清它把"约束交给编译器"的建模价值。

## 题 1：record 和普通类 / Lombok `@Value` 有什么区别？什么场景用 record？

**期望时长**：2 分钟

**答题要点**：

- record 是语言级"透明数据载体"：组件 final、访问器同名、自动 equals/hashCode/toString、隐式 final 不能继承类。
- 比 Lombok 更清晰（语义显式、无注解处理器、编译期生成）。
- 适用：DTO、值对象、Map key、多返回值。
- 不适合：需要继承、需要可变状态、需要复杂 builder 的对象。

**追问链**：record 完全不可变吗？→ 只是浅不可变，组件引用不可变但指向的可变对象仍可改，需防御性拷贝。

## 题 2：sealed 是干什么的？它和 final、abstract 有什么关系？

**答题要点**：sealed 限定"谁能继承/实现我"（`permits`），形成封闭可枚举的类型层级；是 final（完全不可继承）与 abstract（任意可继承）之间的**受控中间态**。子类要么 final、要么 non-sealed、要么继续 sealed。

**追问链**：sealed 最大收益？→ 配合模式匹配做穷尽性检查，新增子类型忘了处理编译期就报错——把状态机/结果类型的完整性交给编译器。

## 题 3：instanceof 模式匹配和 switch 模式匹配分别哪个版本能用？

**答题要点**：

- instanceof 模式匹配 `o instanceof String s`：Java 16 转正，17 可直接用。
- switch 表达式（有返回、箭头不穿透）：Java 14 转正。
- switch **类型模式 / record 解构** `case PaySuccess s ->`：17 起预览，**Java 21 转正**。

**追问链**：17 想用 switch 类型模式怎么办？→ 开 `--enable-preview`；生产更稳的做法是直接上 21（下一节）。

## 题 4：什么是代数数据类型（ADT）？Java 现在怎么表达？

**答题要点**：ADT = "和类型（多种 case）+ 积类型（每个 case 携带多字段）"。Java 用 **sealed interface（和类型）+ record（积类型）+ 模式匹配穷尽处理** 逼近函数式语言的 sealed trait + case class，编译器保证分支完整。

**追问链**：实际业务价值？→ 支付结果、订单状态、HTTP 响应等"有限且互斥的状态"建模，防漏分支、防非法状态，配合不可变天然线程安全。

## 高频速答

- record 能有方法吗？→ 能，可有实例/静态方法、静态字段，但实例字段只有组件。
- record 能定义构造器吗？→ 有规范构造器 + 紧凑构造器，可加额外构造器（须委托主构造器）。
- sealed 的 permits 能省略吗？→ 同文件/同包可省，编译器自动推断直接子类。
- 文本块缩进怎么定？→ 去除所有行（含结束定界符行）的最小公共前导空白。
- switch 表达式里多语句块怎么返回值？→ 用 `yield`（箭头单表达式则直接给值）。
