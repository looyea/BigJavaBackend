### 1. Java 9 模块系统中，专门用于放行"运行时反射深度访问"的指令是？（15分）

- A. `exports`
- B. `requires`
- C. `opens`
- D. `provides`

> 答案：C
> 解析：`exports` 管编译期可读，`opens` 才允许反射访问包内类型的私有成员；Jackson/JPA 等靠反射的库若目标包未 opens，会抛 `InaccessibleObjectException`。

### 2. 关于 `var`（Java 10），下列说法正确的是？（15分）

- A. `var` 让变量变成动态类型
- B. `var` 只能用于带初始化表达式的局部变量，编译期即推断出静态类型
- C. `var` 可用于方法参数和字段
- D. `var x;` 是合法的

> 答案：B
> 解析：`var` 是**局部变量类型推断**，仍是静态类型（编译期定死），必须有初始化值，不能用于字段/方法参数/返回类型。

### 3. 【多选】下列关于 Java 9-11 与企业停在 8/11 的说法，正确的有哪些？（20分）

- A. `List.of/Set.of/Map.of` 返回的是不可变集合
- B. Java 9 起改为半年一版、仅部分为 LTS，企业通常只跟 LTS
- C. JPMS 模块系统被绝大多数业务应用全面采用并从中显著受益
- D. Java 11 引入了标准化的 `HttpClient`，支持 HTTP/2 与异步

> 答案：ABD
> 解析：C 错——JPMS 主要利好平台/类库作者，多数业务应用仍以 classpath 运行、并未真正模块化（迁移摩擦大）。A/B/D 正确。

### 4. 判断：`"   ".isBlank()` 与 `"   ".isEmpty()` 的返回值相同。（10分）

- A. 正确
- B. 错误

> 答案：B
> 解析：`isEmpty` 只在长度为 0 时为 true；`isBlank`（Java 11）对纯空白字符串返回 true，二者不同。

### 5. 填空题：能把"应用 + 其真正依赖的模块"裁剪成精简运行时镜像的工具是 ______；用于分析类/模块依赖关系的工具是 ______。（10分）

> 答案：jlink / jdeps

### 6. 简述 JPMS 想解决的问题、`exports` 与 `opens` 的区别，以及为什么多数企业应用并没有真正模块化。（30分）

> 参考答案：
> - 想解决：巨型 classpath、依赖靠约定不可声明、可见性只有 public 一档、JDK 自身臃肿
> - `exports` 使包在编译期对读方模块可见；`opens` 额外放行运行时反射（给 Spring/Jackson/JPA）
> - `jlink` 裁剪自定义运行时、`jdeps` 分析依赖
> - 未真正模块化原因：迁移摩擦大（反射、SPI、动态代理、native、内部 API 封锁），收益主要归类库作者；Spring 官方长期建议普通应用不模块化
> - 企业停在 8/11：授权成本 + 生态兼容 + 迁移成本 + 只认 LTS 的节奏
