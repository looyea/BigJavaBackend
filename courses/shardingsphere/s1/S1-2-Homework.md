# 分布式主键、读写分离与弹性迁移 · 作业

## 作业 1：主键发号器选型实验

**目标**：用数据验证三种主键的写入代价。

1. 同表结构分别用 Snowflake、UUID、号段模式灌 500 万行，记录耗时与表空间（输出：三者对比表）。
2. 模拟时钟回拨 3s：观察裸 Snowflake 冲突 → 加上"等待+停发"策略复测（错误用例修复练习）。

## 作业 2：读写分离一致性演练

**目标**：复现并修复"支付回调读不到订单"。

1. 主从制造 2s 延迟（人为阻塞回放 SQL）。
2. 下单接口后立即从库查订单 → 必现查不到（结果复现）。
3. 分别用 transactionReadQueryType=PRIMARY 与 HintManager 强制读主修复 → 对比两者影响面（说明：前者管事务、后者管单点）。

## 作业 3：影子库压测配置

**目标**：生产流量镜像写影子表零污染。

1. 配置 shadow 规则：按 `user_id=999999` 压测标路由到 t_order_shadow。
2. 故意漏配表名映射跑 5 分钟压测 → 检查真实表是否被污染（反例验证，随后恢复配置）。
3. 压测报告给出每分片 QPS 分布与热点片占比（验收：最大片流量 < 均值×1.5）。
