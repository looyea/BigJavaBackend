# 对账、清算与资损防控 · 作业

### 作业 1：逐笔对账与差错分类

- 目标：产出一份能区分掉单/长款/短款/金额不符的当日差错清单。
- 任务：给定本地流水与"渠道账单"两份数据(含渠道单号、金额以分为单位)，按单号做集合 diff：渠道有本地无=长款、本地有渠道无=短款、金额不等=金额不符。构造一批含"总额相等但两笔方向对冲差错"的数据验证逐笔 diff 仍能发现。
- 验收标准：清单准确分类三类差错；构造的对冲差错被识别而非被"总额相等"放行；输出带原始凭证便于复核。
- 参考解法要点：金额一律整数分比较、禁止浮点；账单下载带重试与截止(渠道可能延迟)；结果落差错池表而非直接改账。

### 作业 2：差错自动闭环 + 幂等防重复入账

- 目标：让长款/掉单能被自动补单或退款且不产生二次资损。
- 任务：对差错池条目按类型路由处置——长款走补单或原路退款、掉单走主动查单补记；处置动作以差错 ID/渠道单号做幂等键，任务可重跑。模拟"补单成功后任务重跑一次"。
- 验收标准：重跑处置不重复入账、不重复退款；无法自动处置的条目落到"待人工复核"状态；每次处置都留可审计轨迹。
- 参考解法要点：处置复用与回调相同的幂等入账路径；差错状态机(待处理/处理中/已闭环/已转人工)推进用 CAS；绝不手工 UPDATE 余额凑平。

### 作业 3：多边清分轧差与金额口径统一

- 目标：把一笔交易按参与方拆账并轧差成净额划拨，保证清算结果能与账务对平。
- 任务：输入若干笔含商户/平台/渠道手续费/分账方的交易，按参与方清分成应收应付明细；多边轧差算净额；统一四舍五入口径(银行家舍入)后，校验清分后的分方金额之和能与原始交易金额对平(不因舍入丢分)。
- 验收标准：轧差后净额划拨笔数明显少于逐笔转账；分摊舍入不产生"总分差 1 分"的对不平；清分明细可回溯到复式分录。
- 参考解法要点：手续费分摊用"最后一笔兜差"避免累积误差；轧差方向要与科目借贷一致，防止备付金记反；批次对齐营业日。
