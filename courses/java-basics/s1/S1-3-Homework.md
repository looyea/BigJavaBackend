# 作业题 · HashMap 深度解剖

> 不判分，对照参考要点自查。

## 作业 1：容量与阈值计算（必做）

已知 `new HashMap<>()` 默认容量 16、负载因子 0.75。请回答：

1. 放入第几个元素时会触发第一次扩容？
2. 若初始就打算放 100 个键值对，构造参数给多少最合适？写出 `expectedSize / 0.75 + 1` 的计算并向上取 2 的幂。

**参考要点**：第 13 个（16×0.75=12，>12 触发）；100/0.75+1≈134 → 取 2 的幂 256。

## 作业 2：手推桶分布（必做）

给定 5 个 key 的 `hashCode()` 分别为 `1, 2, 17, 33, 1000`，HashMap 容量 16。

1. 先做扰动 `h ^ (h>>>16)`（这些值小，高位为 0，扰动后近似不变）。
2. 用 `(16-1) & hash` 求各自下标。
3. 指出哪些 key 会落进同一桶形成冲突。

**参考要点**：`1→1, 2→2, 17→1, 33→1, 1000→8`；key 1/17/33 同桶（下标 1）。
