# 实际面试题 · 面向对象核心与多态真相

> 收录 2024—2026 国内中大厂 Java 后端真实面试，含追问链。答题要展示"你知道机制的边界"，而不是背名词。

## 题 1：重载和重写的区别？分别在什么时候确定？

**期望时长**：90 秒

**答题要点**：

- 重载：同名不同参数列表，同类内，**编译期**静态分派，依据静态类型 + 实参。
- 重写：签名一致、子类替换实现，**运行期**动态分派，依据对象实际类型查 vtable。
- 加分：重写约束（协变返回、权限只放宽、检查异常不收窄、参数一致）。

**追问链**：

1. `f(null)` 在多个重载里怎么选？→ 最具体适用方法（maximal specific），`String` 比 `Object` 更具体。
2. 重写后 `@Override` 注解能去掉吗？→ 能编译但应保留，它让编译器替你校验签名拼写，防止"你以为重写了其实重载了"。

## 题 2：多态是怎么实现的？说说底层。

**期望时长**：2 分钟

**答题要点**：

- 向上转型 + 重写 + 动态分派三要素。
- 每个类一张虚方法表，子类复制父表后替换被重写项，方法在表中的索引父子一致。
- 字节码 `invokevirtual`/`invokeinterface` 只是符号引用，运行期按实际类型定位。

**追问链**：

1. 为什么 `private/static/final` 方法不能被重写？→ 它们不在 vtable，用 `invokespecial`/`invokestatic` 直接绑定。
2. 多态有性能开销吗？→ 虚调用阻碍内联；但 JIT 对单态调用点会内联退化成分派预测，热点路径过度抽象才是问题。

## 题 3：接口和抽象类怎么选？Java 8 之后接口能写方法体了，还有必要抽象类吗？

**答题要点**：

- 接口=能力契约，可多实现、无状态（只有常量）；抽象类=is-a + 共享字段/构造逻辑。
- 骨架实现（`AbstractList`/`AbstractMap`）就是抽象类价值：把模板方法固化，子类只填差异。

**追问链**：两个接口有同名 default 方法怎么办？→ 实现类必须重写消歧，或用 `X.super.m()` 指定。

## 题 4：父类引用能不能调用子类特有方法？为什么？

**答题要点**：不能，编译期按静态类型解析符号；父类类型里没有该成员，编译不通过。要调子类方法需向下转型 `((Sub)sup).onlyInSub()`，且应 instanceof / 模式匹配先判型。
