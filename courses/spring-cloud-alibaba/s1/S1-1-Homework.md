# 微服务组件选型地图 · 作业

## 作业 1：选型报告撰写

**目标**：为你的当前项目或理想项目写一份微服务技术选型报告。

1. 描述业务背景（行业、团队规模、预估 QPS）。
2. 画出六层架构模型，每层标注选定组件及理由。
3. 列出 2-3 个备选方案并说明为何放弃。
4. 给出部署拓扑图（哪些组件独立部署、哪些嵌入应用）。

## 作业 2：对比实验

**目标**：用 Nacos 与 Consul 分别做服务注册，对比体验。

1. Docker 启动 Nacos standalone 和一个 Spring Boot 应用注册到 Nacos。
2. Docker 启动 Consul 和同一应用注册到 Consul。
3. 杀掉应用进程，观察两者摘除时间、健康检查方式差异。
4. 修改一个配置项，对比推送延迟。

## 作业 3：Seata 模式选择决策

**目标**：给出 3 个场景，写出选择的 Seata 模式及原因。

1. 电商下单（扣库存+创建订单+扣余额）。
2. 银行跨行转账。
3. 用户注册（发欢迎邮件+初始化配置+创建默认地址）。
