# 负荷预测、计量计费与政企信创 · 作业

### 作业 1：可回测的负荷预测服务

- 目标：把模型从离线实验变成能定时出数、能自证误差的服务。
- 任务：构建统一口径特征库(历史负荷 + 天气 + 日历)，按区域训练/加载模型；实现每日定时批量预测未来 N 天并落库；用 MAPE/RMSE 对历史"预测 vs 实际"回测，误差超阈值触发告警。构造一批"在线特征缺列导致口径漂移"的数据观察偏差。
- 验收标准：能定时产出预测并给出误差；线上线下特征口径一致(同输入同结果)；注入误差异常时能告警。
- 参考解法要点：特征口径与训练严格对齐；预测结果与误差同源留档，便于迭代回看。

### 作业 2：阶梯 + 分时电价计费引擎

- 目标：从表底读数算出可审计的电费账单。
- 任务：实现电量=(本期−上期)×倍率−损耗分摊；按阶梯分档 + 峰谷分时分段计价并汇总；计费规则做成可版本化(每账单记录所用规则版本)、可追溯；金额用整数分。构造跨月周期与一档临界用量样本验证分段正确。
- 验收标准：临界用量不出现整单套最高档的错误；峰谷分段金额之和与明细可对平；改规则后旧账单仍能按当时版本复算。
- 参考解法要点：分段计价先切区间再套单价；规则版本随账单快照留存；异常电量/金额挂人工复核。

### 作业 3：内网信创环境的离线部署与回归

- 目标：让方案在"无公网 + 国产栈"下能装能跑能测。
- 任务：把应用与依赖打包成离线升级包，列出去除公网/云托管强依赖的清单；针对国产数据库做 SQL 方言与驱动适配并跑功能 + 性能回归；审计日志设计为 append-only、数据不出域。
- 验收标准：在隔离网成功安装并启动、能离线升级；SQL 方言差异被回归暴露并修复；审计记录不可篡改、关键操作可回溯。
- 参考解法要点：默认离线优先设计；兼容性回归清单化(方言/函数/分页/大小写)；性能落差给出容量评估与调优项。
