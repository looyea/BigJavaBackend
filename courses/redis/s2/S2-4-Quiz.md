# Redis 作为协调服务：锁、限流与计数器 · 小测

> 本卷满分 100 分：单选 7×6=42，多选 2×9=18，简答 1×40=40。

### 1. 用 Redis 加分布式锁，正确的命令形态是（6分）

- A. SET key value（不加任何选项）
- B. SET key value NX PX 30000（不存在才写 + 带过期）
- C. GET key 判断为空再 SET
- D. INCR key

> 答案：B
> 解析：NX 保证"只在不存在时写"的原子抢占，PX 定 TTL 防持锁进程崩溃后死锁；先 GET 再 SET 是竞态非原子。

### 2. 释放锁时最关键的注意事项是（6分）

- A. 直接 DEL key 即可
- B. 用 Lua 原子地"比对持有者 token 再删"，只删自己那把
- C. EXPIRE key 1
- D. 让锁自然过期不用管

> 答案：B
> 解析：不校验持有者的 DEL 会在自己锁过期、他人刚抢占后误删别人的锁；必须 GET==token 才 DEL 且原子执行。

### 3. "看门狗"要解决的问题是（6分）

- A. 监控 Redis 内存
- B. 持锁期间周期性延长 TTL，防止业务未完成锁先过期
- C. 自动重试加锁
- D. 检测死锁并强制释放

> 答案：B
> 解析：固定 TTL 可能短于业务执行时间，锁提前过期导致并发进入临界区；看门狗续期让锁随持有时长动态延长。

### 4. 主从异步复制对 Redis 锁带来的风险是（6分）

- A. 完全没有影响
- B. 主节点确认锁后崩溃，升主的副本没有该锁，可能出现两个持有者
- C. 只会变慢
- D. 会让锁永久存在

> 答案：B
> 解析：这是 AP 架构固有代价——已确认的锁在 failover 后丢失，可能造成双持有；强正确性场景应改用 CP 协调服务。

### 5. 多实例部署下做全局限流，正确做法是（6分）

- A. 每个实例各自本地计数器限流
- B. 用 Redis 原子递增（INCR+EXPIRE / 滑动窗口 ZSET / 令牌桶 Lua）把计数收敛到单一真值源
- C. 靠前端限流
- D. 不限流

> 答案：B
> 解析：本地计数在多实例下形同虚设，只有把计数放 Redis 用原子命令才能对全局生效。

### 6. 下列哪种限流算法允许一定突发且接近生产语义（6分）

- A. 固定窗口计数
- B. 令牌桶
- C. 简单丢弃
- D. 轮询

> 答案：B
> 解析：令牌桶按时间匀速补币、取到才放行，能容忍短时突发；固定窗口有边界突刺问题。

### 7. 关于"用锁保证业务正确性"，正确的态度是（6分）

- A. 只要加了锁，业务就一定正确
- B. 锁可能失效，被保护的操作还应靠幂等/唯一约束兜底
- C. 不需要锁
- D. 锁一定可靠

> 答案：B
> 解析：Redis 锁存在过期、failover 丢失等失效可能，不能当唯一保证；幂等键/数据库唯一约束才是最后防线。

### 8.（多选）一把可用的 Redis 分布式锁应具备（9分）

- A. 抢占原子（SET NX）
- B. 带 TTL 防死锁（PX）
- C. 解锁校验持有者并原子删除
- D. 解锁直接 DEL 不比对 token

> 答案：A、B、C
> 解析：D 是典型错误——不校验持有者会误删他人锁；A/B/C 加看门狗续期才构成完整锁。

### 9.（多选）Redis 不适合当"权威协调器"的场景有（9分）

- A. 强正确性的临界区（如不能双扣的资金操作）
- B. 允许极小概率失效的高并发防重
- C. 对异步复制丢锁零容忍的关键互斥
- D. 高并发全局限流

> 答案：A、C
> 解析：强正确性/零容忍场景应选 ZK/etcd 或数据库约束；B/D 恰是 Redis 协调的合适场景。

### 10. 为一个多实例部署的秒杀服务，用 Redis 实现"防超卖锁 + 全局限流"，并说明其失效边界与兜底。请给出方案。（40分）

> 参考答案：
- 要点1：锁三要素——SET NX PX 抢占加锁、持有者 token 用 Lua 原子比较删除解锁、看门狗续期防提前过期；杜绝先 GET 再 SET 与裸 DEL（10分）
- 要点2：全局限流——用 INCR+EXPIRE 固定窗口或令牌桶 Lua 把计数收敛到 Redis 单一真值源，保证多实例统一生效，容忍可控突发（10分）
- 要点3：认清边界——主从异步复制可能丢锁造成双持有，RedLock 依赖时钟、怕 GC 暂停；强正确性临界区倾向 ZK/etcd 或数据库乐观锁/唯一约束（10分）
- 要点4：兜底——不把业务正确性全压在锁上，扣减用库存唯一约束/CAS 幂等保证即便锁失效也不超卖，与幂等专题形成双保险（10分）
