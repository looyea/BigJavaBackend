# 小测验 · ChatClient、Prompt 模板与结构化输出

> 共 5 题，合计 100 分，≥ 60 分过关。

### 1. Spring AI 提供统一抽象（ChatClient 等）的核心价值是？（15分）

- A. 让模型不再产生幻觉
- B. 屏蔽不同大模型厂商 API 差异，换模型/向量库主要改配置依赖，减少锁定
- C. 自动写好提示词
- D. 免掉所有费用

> 答案：B
> 解析：像 Spring 抽象 JDBC 一样抽象 AI 能力，追求可移植性，降低厂商锁定。

### 2. `ChatClient` 的 `call()` 与 `stream()` 区别是？（20分）

- A. 没区别
- B. call 一次性拿完整回答；stream 返回 `Flux<String>` 做流式（打字机/SSE）
- C. stream 只能同步
- D. call 用于向量、stream 用于图片

> 答案：B
> 解析：call 阻塞式取全量结果，stream 以响应式流增量输出。

### 3. Spring AI 把模型输出映射为强类型 POJO（`.entity(X.class)`）依赖的机制是？（20分）

- A. 反射随机猜字段
- B. `BeanOutputConverter` 依据目标类型生成 JSON Schema 追加到提示，再把返回 JSON 反序列化为对象
- C. 数据库 ORM
- D. XML 解析

> 答案：B
> 解析：结构化输出=自动生成 schema 约束模型输出 JSON + 反序列化回 POJO。

### 4.（多选）关于结构化输出的工程实践，正确的有？（25分）

- A. 模型不保证严格守约，需对解析失败做重试/降级
- B. 用 record/不可变类、字段语义清晰更利于模型填对
- C. 提示词里既要自然解释又要严格 JSON，会提高解析失败率
- D. schema 越复杂越深，弱模型成功率越高

> 答案：ABC
> 解析：D 相反——嵌套越深弱模型越易失败，应尽量拆简单。

### 5. 判断题：`PromptTemplate` 的意义之一是把提示词从硬编码中剥离，便于维护与 A/B 实验。（20分）

- A. 正确
- B. 错误

> 答案：A
> 解析：模板化+变量渲染让提示词可管理、可复用、可实验。
