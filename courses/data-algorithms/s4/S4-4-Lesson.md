# 动态规划

> 动态规划（DP）是算法题的珠穆朗玛，也是"子问题重叠 + 求最优/计数"的正解。
> 它的难不在写代码，而在**定义状态**和**推转移方程**。本节给出一套可复用的思考流程 + 五大经典模型，把 DP 从"玄学"变成"模板"。

## 一、DP 的三个判定信号

一道题适合 DP，通常同时具备：
1. **最优子结构**：大问题的最优解由子问题的最优解拼成。
2. **重叠子问题**：递归会反复计算相同的子问题（分治的反面）。
3. **无后效性**：一旦状态确定，之后的决策不受"以前是怎么到达这个状态的"影响——只依赖当前状态值。

满足 → 用 DP 把重复计算"记下来"，从指数级降到多项式。

## 二、DP 思考五步法（通用流程）

```flow
① 定义状态 dp[i] 到底表示什么（最难也最关键）
② 推导转移方程：dp[i] 由哪些更小的状态算来
③ 确定 base case（最小时的已知值）
④ 确定遍历顺序（保证算 dp[i] 时它依赖的状态已就绪）
⑤ 空间优化（滚动变量 / 降维）
```

其中**①状态定义**决定一切：同样一道题，状态定义不同，难度天差地别。练 DP 本质是练"识别状态"。

## 三、两种写法：记忆化搜索 vs 递推

```java
// 爬楼梯：每次 1 或 2 阶，到 n 阶有几种走法（斐波那契）
// 写法 A：记忆化自顶向下（递归 + 缓存，最接近暴力、最好想）
long[] memo = new long[n+1];
long climb(int i){
    if(i<=2) return i;                        // base
    if(memo[i]!=0) return memo[i];            // 命中缓存，避免重算 → 这就是 DP
    return memo[i] = climb(i-1) + climb(i-2); // 转移
}
// 写法 B：递推自底向上（填表，无递归栈开销，易做空间优化）
long[] dp = new long[n+1]; dp[1]=1; dp[2]=2;
for(int i=3;i<=n;i++) dp[i]=dp[i-1]+dp[i-2];
```

- **记忆化搜索**：好想到、天然处理"可达性不完备"的状态；但有递归栈开销。
- **递推填表**：无栈开销、方便滚动优化；要自己想清遍历顺序。两者等价，初学建议先写记忆化再转递推。

## 四、模型一：线性 DP（打家劫舍 / 最大子数组和）

状态沿一条线推进。

```java
// 打家劫舍：不能偷相邻，求最大金额
// dp[i] = 到第 i 间房为止能偷的最大值；转移：不偷 i → dp[i-1]；偷 i → dp[i-2]+a[i]
int rob(int[] a){
    int prev2=0, prev1=0;                       // 滚动变量，O(1) 空间
    for(int x : a){ int cur=Math.max(prev1, prev2+x); prev2=prev1; prev1=cur; }
    return prev1;
}
// 最大子数组和（Kadane）：dp[i]=max(a[i], dp[i-1]+a[i])，答案取所有 dp[i] 最大
```

套路：`dp[i]` 表示"前 i 个 / 以 i 结尾"的最优，转移枚举"第 i 个选还是不选/怎么选"。

## 五、模型二：背包 DP（0-1 背包 / 完全背包）

**0-1 背包**：n 件物品各一件、容量 W，求最大价值。
- 状态 `dp[i][w]` = 前 i 件、容量 w 的最大价值；转移：不装 i → `dp[i-1][w]`；装 i → `dp[i-1][w-wt]+val`。
- **空间优化成一维**：`dp[w]` 逆序遍历 w（每件只用一次）。

```java
// 0-1 背包一维：容量逆序，保证每件物品只被选一次
int[] dp = new int[W+1];
for(int i=0;i<n;i++) for(int w=W; w>=wt[i]; w--) dp[w]=Math.max(dp[w], dp[w-wt[i]]+val[i]);
```

**完全背包**（每件无限个）：唯一区别是容量**正序**遍历（允许重复选）。这个"逆序/正序"的差别是面试高频考点，也是零钱兑换（求最少硬币、无限个）用正序的原因。

## 六、模型三：二维 / 网格 DP（不同路径 / 最小路径和 / 编辑距离）

状态是 `dp[i][j]`，从上方和左方转移。

```java
// 编辑距离：word1→word2 最少操作数
int minDistance(String a, String b){
    int m=a.length(), n=b.length(); int[][] dp=new int[m+1][n+1];
    for(int i=0;i<=m;i++) dp[i][0]=i;           // base：删成空
    for(int j=0;j<=n;j++) dp[0][j]=j;           // base：从空插入
    for(int i=1;i<=m;i++) for(int j=1;j<=n;j++)
        dp[i][j] = a.charAt(i-1)==b.charAt(j-1)
                 ? dp[i-1][j-1]                                     // 相等：不动
                 : 1 + Math.min(dp[i-1][j-1],                       // 替换
                       Math.min(dp[i-1][j], dp[i][j-1]));           // 删除 / 插入
    return dp[m][n];
}
```

LIS（最长递增子序列）`dp[i]=以i结尾的LIS长度`，O(n²) 或配合二分/ patience 排序降到 O(n log n)——二分（s3-3）与 DP 的漂亮结合。

## 七、模型四：区间 DP

状态定义在区间 `[i,j]` 上，按**区间长度从小到大**枚举（保证小区间先算好）。代表：合并石子、矩阵链乘、最长回文子序列。范式：`dp[i][j] = min/max over k ( dp[i][k] + dp[k+1][j] + cost(i,j) )`。

## 八、空间优化的通用套路

- 二维 `dp[i][j]` 只依赖上一行 → **滚动数组**压成一维。
- 一维 `dp[i]` 只依赖前几个 → 用几个变量代替数组（如打家劫舍的 prev1/prev2）。
- 背包降维要注意**遍历方向**（0-1 逆序、完全正序），错一个方向就重复计或漏计。

## 九、本节要点回顾

1. DP 三信号：最优子结构 + 重叠子问题 + 无后效性；核心难点是"状态定义"。
2. 五步法：定义状态 → 推转移 → base → 遍历顺序 → 空间优化；记忆化与递推等价。
3. 四大模型：线性（打家劫舍/Kadane）、背包（0-1 逆序、完全正序）、二维网格（编辑距离/LIS）、区间（按长度枚举）。
4. 空间优化靠滚动数组/降维，务必守遍历方向以免重复计数。
