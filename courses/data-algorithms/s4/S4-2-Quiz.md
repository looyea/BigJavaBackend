# 小测验 · 递归与分治

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 朴素递归求斐波那契是 O(2ⁿ)，根本原因是？（15分）

- A. 递归本身太慢
- B. 子问题大量重叠，同一个 fib(k) 被反复重算
- C. 没写 base case
- D. 用了全局变量

> 答案：B
> 解析：递归树里 f(n-2) 等被多次计算，重叠子问题正是"应转 DP/记忆化"的信号；分治则要求子问题相互独立。

### 2. 写递归函数时，正确的心智模型是？（15分）

- A. 在脑中逐层展开每次调用
- B. 信任递归能解决更小的子问题，自己只负责组合返回 + 保证 base 和规模递减
- C. 尽量让递归深度越大越好
- D. 必须用全局变量传参

> 答案：B
> 解析：跟踪每一层既痛苦又易爆栈；抓住"基准情形终止 + 每步规模严格递减 + 组合子结果"即可。

### 3. 【多选】关于分治，正确的有哪些？（20分）

- A. 分治把问题切成相互独立的子问题，各解后合并
- B. 子问题独立使分治天然可并行（parallelSort、MapReduce）
- C. 归并 T(n)=2T(n/2)+O(n)，由主定理得 O(n log n)
- D. 分治和动态规划是一回事，可以互换

> 答案：ABC
> 解析：D 错——分治要求子问题独立，DP 针对重叠子问题，二者分水岭正是"是否重叠"，不能互换。

### 4. 判断：递归深度可能到 O(n) 的链式结构，生产上应改迭代 + 显式栈以防 StackOverflowError。（10分）

- A. 正确
- B. 错误

> 答案：A
> 解析：递归占调用栈、深度 O(n) 有溢出风险；用堆上的显式栈可承载更深规模，是把隐式递归改迭代的标准手法。

### 5. 填空题：区分"用分治还是 DP"的关键是子问题是否 ______；主定理比较 ______ 与 b^d 来决定分治复杂度。（10分）

> 答案：重叠 / 有重叠 / a / 系数a

### 6. 说明归并排序为什么是分治、能否并行，以及"并行分治"的瓶颈通常在哪一步、怎么缓解。（30分）

> 参考答案：
> - 归并把数组切成两半独立排序再合并，子问题不重叠 → 典型分治
> - 可并行：左右两半无依赖，能丢给不同线程/机器（parallelSort 用 ForkJoin、MapReduce 用 map 分片）
> - 瓶颈通常在 merge（合并）：合并需跨子结果协调，若有全局锁或必须串行会限制加速比（Amdahl）
> - 缓解：减少合并层数、用多路归并/树形合并让合并也并行、增大数据分片粒度摊薄合并开销
> - 关键：体现"分治可并行的前提是子问题独立，而合并是共享临界点"
