# 小测验 · 动态规划

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 一个问题适合用 DP，通常需要同时具备的三个特征是？（15分）

- A. 有序性 + 稳定性 + 原地性
- B. 最优子结构 + 重叠子问题 + 无后效性
- C. 贪心选择 + 局部最优 + 单调性
- D. 分治 + 归并 + 主定理

> 答案：B
> 解析：DP 靠"最优子结构"递推、靠"重叠子问题"体现记录价值、靠"无后效性"保证只依赖当前状态；三者齐备才适合 DP。

### 2. 0-1 背包降为一维数组时，容量为什么要"逆序"遍历？（15分）

- A. 逆序更快
- B. 保证每件物品在一轮里只被使用一次（不被本轮刚更新的值再次利用）
- C. 为了稳定
- D. 防止溢出

> 答案：B
> 解析：0-1 背包每件至多选一次；一维 `dp[w]` 依赖"上一行"的 `dp[w-wt]`，逆序保证用到的仍是未装入本物品的旧值。完全背包要正序（允许重复选）。

### 3. 【多选】关于 DP 写法与模型，正确的有哪些？（20分）

- A. 记忆化搜索（自顶向下 + 缓存）与递推填表（自底向上）本质等价
- B. 打家劫舍、Kadane 最大子数组和属于线性 DP，可用滚动变量降到 O(1) 空间
- C. 区间 DP 通常按区间长度从小到大枚举，保证子区间先算好
- D. 编辑距离的一维/二维状态是 `dp[i][j]`，转移只有"相等不动、否则取替换/删除/插入三者最小 +1"

> 答案：ABCD
> 解析：四项均正确。A 是两种实现、B 是线性模型、C 是区间枚举顺序、D 是编辑距离转移，都是标准 DP 结论。

### 4. 判断：DP 的核心难点在于写 for 循环，而不是定义状态和推导转移方程。（10分）

- A. 正确
- B. 错误

> 答案：B
> 解析：DP 最难也最关键的是"状态定义"和"转移方程"，代码只是最后一步；状态定义不同，同一题难度天差地别。

### 5. 填空题：DP 的"无后效性"指一旦状态确定，后续决策只依赖 ______ ，与到达它的路径无关；把二维 `dp[i][j]` 压成一维常用 ______ 数组。（10分）

> 答案：当前状态 / 当前状态值 / 滚动

### 6. 给出"零钱兑换最少硬币数"（面额数组 coins、金额 amount，每种硬币无限用）。请写出状态定义、转移方程、base、遍历方向，并说明它是哪种背包、为何面额任意时贪心不行。（30分）

> 参考答案：
> - 状态：dp[i] = 凑出金额 i 所需最少硬币数
> - 转移：dp[i] = min over coin( dp[i-coin] + 1 )，coin ≤ i
> - base：dp[0]=0；其余初始化为 amount+1（表示不可达）；结果若仍为不可达返回 -1
> - 遍历：外层金额 i 从 1..amount，内层枚举 coins —— 属"完全背包"（每种无限用），求最少个数
> - 贪心为何不行：非规范面额（如 {1,3,4} 凑 6）每次取最大得 4+1+1=3 枚，最优 3+3=2 枚，不满足贪心选择性质（呼应 s4-3）
> - 关键：用 dp 枚举"最后一枚是哪种面额"的所有可能取 min，正是重叠子问题 + 最优子结构
