# 课后作业 · 贪心

> 2 题，一题贪心实现，一题贪心证伪，附验收标准与参考答案。

## 作业 1：跳跃游戏（能否到终点 / 最少步数）（50分）

**要求**：
1. `canJump(nums)`：判断能否从下标 0 到达末尾。
2. `minJump(nums)`：若能到达，求最少跳跃次数。

**验收标准**：
- canJump：贪心维护"当前能到达的最远位置 reach"，遍历时若 `i>reach` 说明断档返回 false。
- minJump：层进式贪心，每层推进到当前层能到的最远，跳一次进入下一层。

**参考答案要点**：
```java
boolean canJump(int[] a){ int reach=0;
    for(int i=0;i<a.length;i++){ if(i>reach) return false; reach=Math.max(reach,i+a[i]); }
    return true; }
int minJump(int[] a){ int jumps=0, curEnd=0, far=0;
    for(int i=0;i<a.length-1;i++){ far=Math.max(far,i+a[i]);
        if(i==curEnd){ jumps++; curEnd=far; } }   // 到本层边界就必须再跳
    return jumps; }
```

## 作业 2：判断并证伪/证明下列贪心（50分）

**要求**：对每个策略判断对错，错的给反例：
1. 0-1 背包：按单位价值从高到低贪心装入。
2. 区间"最少箭引爆气球"：按气球右端排序，箭扎在当前未覆盖区间的最右端。
3. 用任意面额凑零钱取最少枚数：每次拿最大面额。

**验收标准**：能给出 1 和 3 的反例、说明 2 正确并给直观证明。

**参考答案要点**：
1. **错**（CLRS 经典反例）。容量 50，物品 A(重10 值60 单位6)、B(重20 值100 单位5)、C(重30 值120 单位4)。按单位价值贪心：先 A 后 B，剩 20 装不下 C，总价值 160；而最优是 B+C=220。0-1 背包不能拆分，单位价值贪心会因"装完高单位价值的却留下无法利用的空容量"而失手，必须 DP。
2. **对**。按右端排序 + 扎最右端，是让一支箭覆盖尽量多后续区间的贪心选择性质，可交换论证。
3. **错**（面额任意时）。反例 {1,3,4} 凑 6：贪心 4+1+1=3 枚，最优 3+3=2 枚；仅规范货币体系才恰好对。
