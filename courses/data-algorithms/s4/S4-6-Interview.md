# 面试考点 · 位运算、前缀和、差分、单调栈与单调队列

> 这一族题的面试价值不在"会不会做"，而在**能否说清为什么是 O(n)**。四个工具全部依赖"均摊分析"或"预处理换查询"，能把这两句话讲出来就是加分项。

## 考点 1：前缀和与它的下标哲学

**起手**：写一个方法，多次查询静态数组的区间和。

**追问链**：
1. `pre` 数组开多大、`pre[0]` 是什么？→ 开 `n+1`，`pre[0]=0`，`pre[i]` = 前 i 个元素之和，这样 `l=0` 不用特判。
2. 区间和公式？→ `pre[r+1] - pre[l]`。
3. 用什么类型？→ `long`；累加和超 21 亿就是 `int` 溢出事故，这是主动展示工程敏感度的机会。
4. 二维怎么推？→ 容斥：`pre[i+1][j+1] = pre[i+1][j] + pre[i][j+1] - pre[i][j] + a[i][j]`，强调"不要背符号，画矩形看谁被加了两次"。

## 考点 2：和为 k 的子数组个数（LC 560，最高频）

**起手**：数组含负数，求和为 k 的连续子数组个数。

**期望**：前缀和 + 哈希计数，`ans += cnt[cur - k]`，然后 `cnt[cur]++`，初始 `cnt.put(0L, 1)`。

**追问链**：
1. 为什么不能用滑动窗口？→ 含负数则窗口和不单调，收缩方向不确定。**这题几乎必然被拿来和"长度最小的子数组（全正，可用滑窗）"对比考察**，答出这个分界判据就赢了。
2. `cnt.put(0L,1)` 去掉会怎样？→ 漏掉所有从下标 0 开始、前缀和恰为 k 的子数组。
3. 为什么是"查询后再计数"？→ 保证 `i < j` 的顺序，避免自身与自己配对（`k=0` 时会错）。
4. 若求"和能被 K 整除的子数组"？→ 键换成 `((cur % K) + K) % K`（Java 取模会为负，必须修正）。
5. 若求"最长和为 k 的子数组"？→ 哈希存"该前缀和**首次**出现的下标"，长度取 `i - firstIdx`。

## 考点 3：差分及其适用边界

**起手**：n 次操作，每次给区间 `[l,r]` 加 v，最后输出整个数组。

**期望**：`d[l]+=v; d[r+1]-=v`，最后求一次前缀和还原；O(n + m)。

**追问链**：
1. 什么时候不能用差分？→ 需要**在线**（改一次就要立刻查询）时差分不够，要树状数组/线段树；差分是"离线批量改 + 末尾统一还原"。
2. 时间轴范围 10⁹ 怎么办？→ 离散化，或改用端点排序扫描（会议室问题）。
3. 二维差分怎么写？→ 四点打点，符号与前缀和镜像，同样靠容斥。
4. 追问"区间加等差数列"？→ 差分的差分（二阶差分），说明本质是"用高阶差分把非线性变化降为常量"。

## 考点 4：单调栈（下一个更大 / 柱状图 / 接雨水）

**起手**：给每个元素找右边第一个比它大的元素。

**追问链**：
1. 栈里存什么、维持什么单调？→ 存**下标**；栈内值**递减**（因为它们都还在"等待更大的值"）。
2. 复杂度凭什么是 O(n)？→ 每个下标最多进栈一次、出栈一次，`while` 内 `pop` 总数 ≤ n —— **均摊分析**，不是"两层循环所以 O(n²)"。
3. 柱状图最大矩形的宽度为什么是 `right - left - 1`？→ 两侧边界都是"第一个严格更矮"的位置，取不到。
4. 相等时用 `>=` 还是 `>`？→ 一侧 `>=` 一侧 `>` 归属唯一；两侧都 `>=` 结果仍正确（等高区间合并到最左柱）。能讲清这一点极少见。
5. 变体抽查：每日温度、接雨水（按层）、有效括号、"移除 k 位使数最小"（字典序单调栈）。

## 考点 5：单调队列与滑动窗口最值

**起手**：长度为 k 的窗口右移，输出每个窗口的最大值。

**期望**：`Deque` 存下标，队头最大；三步：队尾淘汰 `<=` 当前的 → 入队 → 队头踢过期 `<= i-k` → 读队头。

**追问链**：
1. 为什么队头就是当前窗口最大值？→ 队列保持值递减，被淘汰者"又旧又小"，在新元素出窗前不可能夺冠。
2. 为什么淘汰用 `<=` 而不是 `<`？→ 相等时保留更新的下标即可，旧的那个永远不会再成为答案，留着只占位。
3. 为什么不用优先队列（堆）？→ 堆删除任意元素是 O(log n) 且要懒删除，总 O(n log n)；单调队列均摊 O(n)。**这题是"堆 vs 单调队列"取舍的标准答案**（呼应 s2-3）。
4. 追问：窗口最值 + 约束（如"子数组最大不超过 limit 的最长子数组"）怎么组合？→ 单调队列维护最值 + 双指针维护左边界（呼应 s4-1）。

## 考点 6：位运算

**起手**：数组中除一个元素外其余都出现两次，O(1) 空间找出它。

**期望**：全体异或，成对抵消。

**追问链**：
1. 其余出现三次呢？→ 逐位统计 1 的个数对 3 取模；或 `ones/twos` 双掩码状态机。
2. 有两个落单数呢？→ 全体异得 `x^y`，`lowbit = (x^y) & -(x^y)` 取任一位两数不同的 bit，按该位分组分别异或。
3. `x & (x-1)` 的作用？→ 消掉最低位的 1；用于判 2 的幂、`while(x!=0){x&=x-1;cnt++;}` 数 1（但生产直接用 `Integer.bitCount`，编译为 POPCNT 单指令）。
4. 陷阱题：`1 << 31` 是什么？`1 << 32` 呢？→ 前者 `Integer.MIN_VALUE`；后者按 `n & 31` 取模等于 `1 << 0 = 1`，静默出错；要 63 位得写 `1L << 63`。
5. 状态压缩：n 个元素的集合用 `int` 表示，`mask | (1<<i)` 加入、`mask & (1<<i)` 判断；状压 DP 只做 n ≤ 20 的理由（2²⁰ ≈ 10⁶ 状态）。
6. 工程视角：订单/风控标志位用一个 `long` 存而不是五个 `tinyint`，位过滤可走索引；但一旦需要"按单个标志建索引/查询"就要权衡，位掩码不可扩展（超过 64 位就得换 `BitSet`）。

## 考点 7：树状数组（区分度考点）

**起手**：既要不定期修改单个元素，又要频繁查前缀和。

**期望**：树状数组，`add` 与 `sum` 均 O(log n)；`i += i & -i` 与 `i -= i & -i` 两条轨道。

**追问链**：
1. `i & -i` 是什么？→ `lowbit`，取最低位的 1；`t[i]` 负责长度恰为 `lowbit(i)` 的一段。
2. 和线段树比？→ 代码短、常数小、缓存友好；但只擅长"前缀/区间和、单点改"，任意区间最值需线段树。
3. 高频应用：求**逆序对个数**（值域 BIT 从右往左累加）、"统计右侧更小元素个数"；与归并排序分治解法互为对照（呼应 s3-2、s4-2）。
4. 差分 + BIT 可实现"区间改 + 区间查"（两棵 BIT），能说清就是资深水平。

## 考点 8：识别信号（面试官最想听的元能力）

| 题目里出现的信号 | 应当立刻想到 |
|---|---|
| "多次查询区间和/异或/统计" | 前缀和（静态）/ 树状数组（动态） |
| "多次给区间整体加/减，最后看结果" | 差分 |
| "第一个比它大/小的元素""上一个更矮的墙" | 单调栈 |
| "窗口内的最大/最小值" | 单调队列（或堆 + 懒删除） |
| "成对抵消""出现一次/三次""n ≤ 20 枚举子集" | 异或 / 状压 |
| 含负数的区间和、子数组计数 | 前缀和 + 哈希（不是滑窗） |
| 要求输出具体路径 / 所有方案 | 回溯（DP 会丢路径，呼应 s4-5） |

**红线提示**：这类"模板题"答完一定要主动补一句复杂度与为什么，并说明适用边界（例如"差分只能离线批量改"）。只写对代码不讲边界，是中级；讲清边界与失效条件，才是架构师视角。
