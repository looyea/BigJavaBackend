# 面试考点 · 双指针与滑动窗口

> 手撕高频区。面试官看"能否识别问题信号 → 套模板 → 讲清为什么 O(n)"。

## 考点 1：什么信号想到滑动窗口

**起手**：什么时候用滑动窗口？

**追问链**：
1. 信号？→ 求"连续"子数组/子串 + 一个关于窗口的条件（和/去重/覆盖/定长）。
2. 为什么是 O(n)？→ right 扩张、left 只在违规时收缩，各自单向最多 n 步，总移动 ≤ 2n。
3. 求最长 vs 最短模板差别？→ 最长"违规才收缩、合法后更新"；最短"合法就尝试收缩并更新"。
4. 定长窗口？→ 维持 `right-left+1==k`，超出即移 left。

## 考点 2：对撞 vs 快慢，怎么选

**起手**：双指针有哪几种？

**期望**：
- 对撞（左右夹逼）：有序数组配对/夹逼出目标，靠单调性丢弃。
- 快慢（同向）：原地去重/移动零（slow 写指针）、链表判环/找中/倒数 k。
- 追问：无序数组配对求和能用对撞吗？→ 不能，要先排序(变 O(n log n))或改用哈希。

## 考点 3：Floyd 判圈（快慢指针招牌）

**起手**：如何 O(1) 空间判断链表有环并找入口？

**追问链**：
1. 判环？→ 快(两步)慢(一步)必在环内相遇。
2. 找入口？→ 相遇后一指针归头、同速走，重逢点即入口。
3. 为什么？→ 由 `a = k·c − b` 的距离关系推出（能推导即达优秀线）。
4. 为什么不用 HashSet？→ 那要 O(n) 空间，O(1) 是本题真正考点。

## 考点 4：滑动窗口的真实工程应用

**起手**：滑动窗口只在刷题里有用吗？

**期望**：
- 限流滑动窗口计数器（Sentinel/Nginx）：时间分桶滚动统计请求数。
- 监控滑动平均、错误率窗口、连续超标告警。
- 追问：为什么用分桶而不是记录每个时间戳？→ 记录全部会内存爆炸且统计要扫；分桶压缩成固定格子增量维护，是精度与内存的折中。

## 考点 5：滑动窗口失效的情况

**起手**：什么样的题不能用滑动窗口？

**期望**：
- 窗口不具单调性（收缩不一定让条件变合法/更差），典型"含负数的子数组和=target"→ left 无法只进不退，改用**前缀和 + 哈希**（见 s4-6）。
- 能识别"要不要连续 + 单调性成不成立"即达及格线。
