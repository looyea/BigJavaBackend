# 小测验 · 位运算、前缀和、差分、单调栈与单调队列

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 求"和为 k 的子数组个数"（数组含负数），正确且最优的做法是？（15分）

- A. 滑动窗口，因为窗口和最值类问题都是滑窗
- B. 前缀和 + 哈希表计数：边扫边查 `cur - k` 出现过几次，初始放 `cnt.put(0L, 1)`
- C. 排序后二分
- D. 单调栈

> 答案：B
> 解析：含负数时窗口和不具单调性，扩张/收缩不保证正确，滑窗失效（这是"前缀和 vs 滑窗"的分界判据）。前缀和把 `sum(i..j)=k` 变形为 `pre(i)=pre(j+1)-k`，配哈希计数得 O(n)；漏掉 `cnt.put(0L,1)` 会少计从下标 0 开始的子数组。

### 2. 对差分数组 `d` 给区间 `[l, r]` 整体加 `v`，正确的打点是？（15分）

- A. `d[l] += v; d[r] -= v;`
- B. `d[l] += v; d[r + 1] -= v;`（`r+1` 越界时需多开一格）
- C. `d[l] -= v; d[r + 1] += v;`
- D. `d[0] += v; d[r] -= v;`

> 答案：B
> 解析：对 `d` 求前缀和还原时，`+v` 从 `l` 传导到末尾，`r+1` 处的 `-v` 把 `r` 之后抵消，净效果只作用于 `[l, r]`。m 次区间修改由 O(n·m) 降为 O(n+m)。

### 3. 【多选】关于单调栈与单调队列，正确的有哪些？（20分）

- A. 两者都应存**下标**而非值，因为答案常需要位置/距离信息
- B. "每日温度"里栈内保持温度递减，因为栈顶元素正在等待"下一个更大值"来终结它
- C. 单调栈 O(n) 的依据是均摊分析：每个下标最多入栈一次、出栈一次
- D. 滑动窗口最大值的动作顺序是：队尾淘汰不可能再成为最大值的 → 当前元素入队 → 队头踢出过期下标 → 读队头作为答案

> 答案：ABCD
> 解析：四项皆为核心结论。A/B 说明"存下标 + 维持何种单调"的理由；C 是均摊复杂度（呼应 s1-1）；D 顺序写反（先踢过期再入队之外的组合）会取到出窗旧值。补充：求"更大"栈内递减、求"更小"栈内递增，方向反了全错。

### 4. 判断：`1 << 31` 在 Java 中是一个正数，且当移位数 `n = 40` 时按 40 位实际生效。（10分）

- A. 正确
- B. 错误

> 答案：B
> 解析：`1 << 31` 等于 `Integer.MIN_VALUE`（负数）；`int` 左移位数按 `n & 31` 取模，`1 << 40` 实际是 `1 << 8`，静默出错。要操作 63 位必须写 `1L << 63`。

### 5. 填空题：统一的前缀和定义是 `pre[0] = ______`、`pre[i]` 表示 ______ ，于是闭区间 `[l,r]` 的和为 ______ ；树状数组里 `i += i & -i` 中的 `i & -i` 叫做 ______ 。（10分）

> 答案：0 / 前 i 个元素之和 / pre[r+1] - pre[l] / lowbit / 最低位的1

### 6. 柱状图中最大的矩形（LC 84）：说明单调栈在这里求的是什么，宽度公式为何是 `right - left - 1`，并解释两侧都用 `>=` 为什么结果仍然正确。（30分）

> 参考答案：
> - 对每根柱子 `i`，用单调栈求它**左边第一个严格更矮**的下标 `left[i]` 与**右边第一个严格更矮**的下标 `right[i]`，即以 `h[i]` 为高度能向两侧扩展的最大区间
> - 两侧边界都是"取不到"的位置（第一个更矮者本身不能包含），故宽度 = `right[i] - left[i] - 1`；空集时用哨兵 `-1` 与 `n`
> - 全程 O(n)：每个下标进出栈各一次（均摊），栈内维持高度递增
> - 都用 `>=` 的结果仍正确：等高的柱子会把宽度一路合并到最左边那根上，某根柱子的扩展区间虽然被"截短"，但同一高度在最左柱子上算出了完整宽度，面积不丢；若严格一侧 `>`、一侧 `>=` 则每段等高区间的归属唯一，是更"干净"的写法
> - 加分：`(long) h[i] * width` 必须强转防溢出；此模型同构于"以最矮报价为统一成交价求最大成交额"的价格-深度扫描
> - 加分：说明为何不用分治（s4-2）——最坏有序数组退化为 O(n²)，而单调栈严格 O(n)
