# 贪心

> 本节难度：★★★☆☆
> 重要程度：★★★★☆
> 学习产出：贪心选择性质 + 最优子结构的证明、交换论证、区间调度/霍夫曼，以及必须退回 DP 的反例。

> 贪心 = 每一步都取**当前看起来最优**的选择，且**不回头**，希望一路局部最优导向全局最优。
> 它快（常 O(n log n) 排序 + O(n) 扫描），但**危险**：正确性必须证明，证不出来就得退回动态规划（s4-4）。这一节的核心不是"怎么写"，而是"**敢不敢用**"。

## 一、贪心成立的两条铁律

一道题能用贪心，必须同时满足：

1. **贪心选择性质**：存在一个局部最优选择，做出它之后**仍能构造出全局最优解**（即"第一步可以贪"）。
2. **最优子结构**：做完这个选择后，剩下的子问题的最优解 + 本次选择 = 原问题的最优解。

两条都成立，贪心才对。**只要有一条不保证，贪心就会给出错误答案。**

## 二、经典正确案例：区间调度

"最多能安排多少个互不重叠的会议"——**按结束时间升序，能选就选**：结束越早，给后面留的空间越大。

```java
// 例子目的：区间调度——按结束时间升序、能选就选，求最多能安排的互不重叠会议数
int[][] iv = {{1, 3}, {2, 5}, {3, 4}, {4, 6}};
Arrays.sort(iv, (a, b) -> Integer.compare(a[1], b[1]));   // 用 compare 防减法溢出（a[1]-b[1] 极大极小相减会翻符号）
int end = Integer.MIN_VALUE, count = 0;                    // end 必须是 MIN_VALUE：写 0 会把起始为 0 的会议误拒
for (int[] m : iv) if (m[0] >= end) { count++; end = m[1]; }   // 开始不早于上一个结束就选，选完抬高水位线
System.out.println(count);                                 // 正确使用结果：输出 3（选 [1,3]、[3,4]、[4,6]）
// 错误用法：按开始时间排序后贪心 → 同一数据得 2（先选 [1,3] 后 [2,5] 阻塞了 [3,4]），不报错但答案错
// 错误用法：比较器写成 (a, b) -> a[1] - b[1] 且结束时间含 Integer.MAX_VALUE → 减法溢出抛不出异常，排序错乱静默给错答案
```

正确性用**交换论证**证明：任一最优解都能把"第一个会议"替换成"结束最早的那个"而不会变差，于是存在一个以贪心选择开头的最优解，归纳即可。

## 三、怎么证明贪心对：交换论证

**交换论证（exchange argument）** 是贪心证明的标准武器：
1. 取任意一个最优解 O。
2. 证明可以把它"改造"成"第一步就用我的贪心选择"，且改造后**不比 O 差**（仍是最优）。
3. 对剩余子问题递归套用 → 存在一个完全等于贪心解的最优解。

**推翻贪心只需一个反例**：构造一个小数据，让贪心得不到最优。

## 四、贪心会错的经典反例

**找零问题（非规范面额）**："用 {1,3,4} 凑 6，最少几枚"——
- 贪心（每次拿最大面额）：4 + 1 + 1 = **3 枚**。
- 最优：3 + 3 = **2 枚**。

贪心在此**不满足贪心选择性质**：先拿最大的 4 反而堵死了 3+3 的更优解。这类"0-1 背包、非规范面额凑零钱"必须用 **DP**。

```java
// 例子目的：把"贪心找零"跑起来，当场暴露它在非规范面额上的错误结果
int[] coins = {1, 3, 4}; int target = 6;
int remain = target, sheets = 0;
for (int c = coins.length - 1; c >= 0; c--) { sheets += remain / coins[c]; remain %= coins[c]; }   // 每次拿当前最大面额
System.out.println(sheets);   // 贪心结果输出 3（4+1+1）
// 正确答案是 2（3+3）：贪心不报错、也不抛异常，只是默默给出错误金额枚数——这就是"证不出就不敢用"的原因
// 错误用法后果：生产系统用它算最优拆单/找零 → 成本比最优多一枚起，量大即真实亏损；金额类一律改用 DP（s4-4 完全背包）
```

> 经验法则：**规范货币体系（如人民币 1/2/5/10…）贪心恰好对**，但那是特例不是通法；题目一旦面额任意，立刻退回 DP。

## 五、贪心 vs DP 的抉择

| 特征 | 倾向 |
|---|---|
| 能证明贪心选择性质 + 最优子结构 | 贪心（更快、更省空间） |
| 证不出、或存在"局部最优挡死全局最优"的反例 | DP |
| 子问题独立可分治 | 分治 |
| 要枚举所有解 | 回溯 |

## 六、常见可用贪心的题型

- **区间类**：会议室数量、无重叠区间、射击气球（按端点排序贪心）。
- **霍夫曼编码**：每次合并两个最小权值（用堆，见 s2-3）——贪心 + 优先队列的典范。
- **分数背包**：按单位价值贪心取（0-1 背包不行，见反例）。
- **跳跃游戏 / 最少平台数**：维护当前能到的最远/边界。

## 七、本节要点回顾

1. 贪心 = 每步取局部最优且不回头，快但需证明；两条铁律是"贪心选择性质 + 最优子结构"。
2. 证明用交换论证，推翻只需一个反例；区间调度（按结束时间）是标准正确案例。
3. 非规范面额找零、0-1 背包是贪心会错的典型，必须退回 DP。
4. 工程直觉：先想贪心（快），拿不准就用小数据暴力对拍验证，验不过就老实用 DP。
