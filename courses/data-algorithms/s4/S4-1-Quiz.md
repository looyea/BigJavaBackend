# 小测验 · 双指针与滑动窗口

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 有序数组用对撞双指针求两数之和，复杂度是？（15分）

- A. O(n²) / O(n)
- B. O(n) / O(1) 空间
- C. O(n log n) / O(n)
- D. O(1) / O(1)

> 答案：B
> 解析：数组有序时左右夹逼每步安全丢弃一端，单遍 O(n)、只用两个指针 O(1)，比哈希方案更省内存。

### 2. 滑动窗口能把"枚举所有满足条件的连续子数组"从 O(n²) 降到 O(n)，关键在于？（15分）

- A. 用了哈希表
- B. 每个元素最多进窗口一次、出窗口一次，left 从不回退
- C. 递归剪枝
- D. 二分了答案空间

> 答案：B
> 解析：right 单向扩张、left 只在违规时同向收缩，二者都只朝一个方向走，总移动 ≤ 2n，故均摊 O(n)。

### 3. 【多选】关于双指针/滑动窗口，正确的有哪些？（20分）

- A. 快慢指针可用 O(1) 空间判断链表是否有环（Floyd 判圈）
- B. 求最短满足条件的窗口时，应在窗口合法时尝试收缩左边界并更新答案
- C. 对撞双指针可以随意用在任何无序数组的配对求和上
- D. 原地"移动零/删除重复项"用快慢指针可 O(1) 额外空间完成

> 答案：ABD
> 解析：C 错——对撞双指针依赖"有序"带来的单调性，无序数组要么先排序要么改用哈希。A/B/D 均正确。

### 4. 判断：滑动窗口要求"扩张/收缩对条件的影响是单调的"，否则 left 需要回退、模板失效。（10分）

- A. 正确
- B. 错误

> 答案：A
> 解析：正因为窗口有单调性（扩张只会更易违规、收缩只会更易合法），left 才能只进不退；不满足时得换前缀和+哈希等其他方法。

### 5. 填空题：链表判环的 Floyd 算法用一快（每次两步）一慢（每次 ______ 步）指针，相遇即有环；找环入口时把一个指针归 ______、两指针同速再走，重逢点即入口。（10分）

> 答案：一 / 1 / 头 / 起点 / head

### 6. 电商实时接口要统计"过去 1 小时内每个 IP 的请求数，超过阈值就限流"。请用滑动窗口思想设计，说明数据结构、如何保证 O(1) 均摊、以及高并发下要注意什么。（30分）

> 参考答案：
> - 时间轴分桶（如每秒一格，环形数组维护 3600 格）构成滑动窗口计数器
> - 每秒窗口右移一格、丢弃最旧一格，单格进出各一次 → 均摊 O(1)，总量用变量增量维护
> - 相比"记录每个请求时间戳再全量统计"避免 O(n) 扫描
> - 数据结构：环形数组/Deque 存各桶计数 + 一个总计数
> - 高并发：桶计数用 LongAdder/分片或 Redis（滑动日志用 ZSet 按时间戳）避免热点锁；注意时钟与窗口对齐、内存上界固定
> - 关键：把请求流当 right 入窗、过期当 left 出窗，是滑动窗口的时间版应用
