# 面试考点 · 动态规划

> DP 是面试区分度最高的板块。考的是"状态怎么定义、转移怎么推、和暴力/其他范式的区别"，而非背题。

## 考点 1：DP 三要素与识别

**起手**：怎么判断一道题是不是 DP？

**追问链**：
1. 三个特征？→ 最优子结构 + 重叠子问题 + 无后效性。
2. 和分治的区别？→ 子问题是否重叠：重叠用 DP，独立用分治。
3. 和记忆化搜索什么关系？→ 记忆化 = 自顶向下 DP，本质等价，只是实现方向不同。

## 考点 2：状态定义与转移（核心）

**起手**：给你一个没见过的 DP 题，你怎么下手？

**期望**：
- 先想"用什么刻画子问题"：常见 `dp[i]`=前 i 个/以 i 结尾的最优；二维 `dp[i][j]` 表两个序列/网格。
- 推转移：枚举"最后一步的选择"（选/不选、来自上方/左方）。
- 定 base 与遍历顺序（保证依赖项已就绪）。
- 能现场把"打家劫舍/爬楼梯"的状态与转移讲清即达及格线。

## 考点 3：背包全家桶

**起手**：0-1 背包和完全背包代码差在哪？

**追问链**：
1. 0-1 一维为何逆序？→ 保证每件只用一次（不被本轮更新值再利用）。
2. 完全背包？→ 正序（允许重复选）。
3. 求"凑法数""最少硬币数"分别是哪种？→ 凑数完全背包变种（计数）、最少硬币完全背包取 min。
4. 追问：如何还原"选了哪些物品"？→ 记录路径或从 dp 表回溯。

## 考点 4：经典题的转移（抽查）

**起手**：说几个经典 DP 的状态与转移。

**期望**：
- 编辑距离 `dp[i][j]`：相等取 `dp[i-1][j-1]`，否则 `1+min(替换,删除,插入)`。
- LIS `dp[i]=以i结尾`，可优化到 O(n log n)（配合二分）。
- 最大子数组和 Kadane：`dp[i]=max(a[i], dp[i-1]+a[i])`。
- 不同路径/最小路径和：网格 `dp[i][j]=上+左`。

## 考点 5：空间优化

**起手**：DP 怎么省内存？

**期望**：
- 二维只依赖上一行 → 滚动数组降一维；一维只依赖前几项 → 几个变量。
- 关键红线：降维后必须守住**遍历方向**（背包逆序/正序），否则重复计数或漏算——这是最能暴露"背过 vs 真懂"的点。
