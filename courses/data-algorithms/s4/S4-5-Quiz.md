# 小测验 · 回溯与搜索

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 回溯模板中"撤销选择"这一步的根本作用是？（15分）

- A. 让代码更易读
- B. 保证返回上一层时共享的 `path` 状态与进入前严格一致，从而复用同一条路径数组遍历整棵决策树
- C. 降低时间复杂度量级
- D. 避免整数溢出

> 答案：B
> 解析：`path` 是跨递归层共享的可变对象，不撤销就会带着下一层的污染回到上层，产生错误解。撤销使 DFS 空间只需 O(树高)，这是它相对 BFS（O(树宽)）的核心优势。

### 2. 求 `[1,2,3]` 的所有**子集**与所有**排列**，两层循环的起点分别该怎么给？（15分）

- A. 子集用 `start`（且递归传 `i+1`），排列用 `used[]` 遍历全集
- B. 两者都用 `start`
- C. 两者都用 `used[]`
- D. 子集用 `used[]`，排列用 `start`

> 答案：A
> 解析：子集/组合无序，用 `start` 强制索引升序天然避免 `[1,2]`/`[2,1]` 重复；排列有序，每层必须能从全集里挑未用过的元素，故用 `used[]`。

### 3. 【多选】关于去重、剪枝与复杂度，正确的有哪些？（20分）

- A. 含重复元素的组合去重写法是：先排序，再 `if (i > start && nums[i] == nums[i-1]) continue;`
- B. 把上述条件写成 `i > 0` 会误杀 `[1,1]` 这类同一条路径内的合法重复解
- C. 全排列的时间复杂度是 O(n·n!)，子集是 O(n·2ⁿ)
- D. N 皇后可用 `row-col` 与 `row+col` 两个标记数组把"是否与已放皇后冲突"降到 O(1)

> 答案：ABCD
> 解析：A/B 是同层去重的关键与其陷阱（不同层允许相同值）；C 由解的个数 × 每个解长度得出；D 是同一斜线上的坐标不变量，配合列标记即三类约束 O(1) 判定。

### 4. 判断：题目要求"输出所有可行方案"时，也应优先写动态规划，因为 DP 更快。（10分）

- A. 正确
- B. 错误

> 答案：B
> 解析：DP 在压缩时只保留最优值/计数，丢掉了路径信息。要求枚举全部方案或输出具体路径时必须用回溯；常见两段式是"DP 算可行边界 + 回溯构造答案"。

### 5. 填空题：组合总和（元素可重复使用）递归时应传 ______ 而不是 ______；收集答案时必须对 `path` 做 ______ ，否则结果集里全是空列表。（10分）

> 答案：i / i+1 / 拷贝快照 / new ArrayList<>(path) / 快照

### 6. 画出 `[1,2,3]` 子集问题的决策树，说明"答案在叶子还是沿途收集"；再写出回溯三段式，并说明回溯与 s3-1 的图 DFS 的唯一本质区别。（30分）

> 参考答案：
> - 决策树：根为 []，第一层分叉 [1]/[2]/[3]，[1] 下再分 [1,2]/[1,3]，[1,2] 下 [1,2,3]；共 8 个节点
> - 子集问题**沿途每个节点都是一个解**（含空集），故在进入函数时就 `res.add(new ArrayList<>(path))`；而排列/组合总和只在满足结束条件的叶子收集
> - 三段式：做选择（`path.add` + 更新状态）→ 递归进入下一层 → 撤销选择（`path.remove` + 还原状态，`used[]` 也要还原）
> - 与图 DFS 的区别：图的"访问标记"只需单向置位、无需撤销（走过的节点不必再回到未走过状态）；决策树的 `path`/约束集必须在离开节点时精确还原，否则兄弟分支被污染
> - 加分点：指出剪枝分可行性/最优性/对称性三类，BFS 存整层故空间 O(树宽)
