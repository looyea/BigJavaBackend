# 面试考点 · 贪心

> 贪心的面试价值在"敢不敢用 + 怎么证明/证伪"，而不只是写出代码。

## 考点 1：贪心成立的条件

**起手**：你怎么判断一个问题能用贪心？

**期望**：
- 两条铁律：贪心选择性质（局部最优能导向全局最优）+ 最优子结构。
- 追问：怎么确认成立？→ 交换论证证明，或小数据对拍；证不出就用 DP。
- 追问：怎么快速否定一个贪心？→ 构造反例（如非规范面额找零 {1,3,4} 凑 6）。

## 考点 2：区间调度为什么按"结束时间"

**起手**：最多不重叠会议数，为什么按结束时间排序贪心，而不是开始时间或时长？

**期望**：
- 结束越早给后面留空间越大；用交换论证：任何最优解的第一个会议都可替换成"最早结束的那个"而不变差。
- 追问：按开始时间贪心错在哪？→ 开始早但可能很长，挤掉后面更多会议（给反例）。
- 追问：按最短时长呢？→ 也错，短的可能卡在两个长的中间，破坏更优组合。

## 考点 3：贪心 vs DP 的边界

**起手**：分数背包能用贪心，0-1 背包为什么不行？

**期望**：
- 分数背包可拆分物品 → 按单位价值贪心成立。
- 0-1 背包不可拆 → 装完高单位价值的留下用不上的空容量（举 CLRS 反例），需 DP（见 s4-4）。
- 体现"贪心选择性质是否成立"的判断力。

## 考点 4：贪心 + 其他结构的组合题

**起手**：举一个需要配数据结构的贪心。

**期望**：
- 会议室数量：按开始时间排序 + 最小堆维护最早结束的会议室复用；等价"最大并发 = 最少房间"（扫描线/差分）。
- 霍夫曼编码：每次取两个最小权合并 → 用堆，贪心构造最优前缀码。
- 能写出"排序 + 堆/双指针"的贪心即达优秀线。
