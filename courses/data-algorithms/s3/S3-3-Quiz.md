# 小测验 · 查找与二分

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 二分能用（可折半丢一半）的本质前提是？（15分）

- A. 数组必须严格升序且无重复
- B. 存在一个随下标单调的判定，使被丢弃的一半必不含答案
- C. 数组长度必须是 2 的幂
- D. 必须用递归实现

> 答案：B
> 解析：二分核心是"单调可行性"，数组有序只是它最常见的特例；旋转数组、二分答案都是靠某种单调判定，而非表面有序。

### 2. `mid = lo + ((hi - lo) >> 1)` 相比 `(lo + hi) / 2` 解决了什么？（15分）

- A. 更快
- B. 防止 lo+hi 超出 int 上界溢出为负
- C. 结果不同
- D. 支持负数下标

> 答案：B
> 解析：`(lo+hi)` 可能溢出成负数导致数组越界；先减再加避免溢出，右移等价除 2。这是 JDK binarySearch 历史上的坑。

### 3. 【多选】关于二分边界与旋转数组，正确的有哪些？（20分）

- A. 求 target 出现次数可用 `upperBound - lowerBound`
- B. 旋转数组每步 mid 切开后必有一半是有序的，据此判断收缩方向
- C. 旋转数组含大量重复元素时仍一定保持 O(log n)
- D. lowerBound 通常写作左闭右开 `[lo,hi)`，循环用 `lo<hi`、命中收 `hi=mid`

> 答案：ABD
> 解析：C 错——有重复时 `a[lo]==a[mid]` 无法判断哪半有序，需 `lo++` 去歧义，最坏退化 O(n)。A/B/D 均正确。

### 4. 判断："送包裹的最小载重""Koko 吃香蕉最小速度"这类题适合用二分答案。（10分）

- A. 正确
- B. 错误

> 答案：A
> 解析：载重/速度越大越容易在约束内完成（单调可行），对答案二分 + `check(mid)` 模拟判定即可把最优化转成 O(log 值域) 次判定。

### 5. 填空题：找"第一个 ≥ target"用 ______；把"求最小可行 x"转化为对 x 判定的函数通常叫 ______。（10分）

> 答案：lowerBound / 下界二分 / check / 判定函数

### 6. 设计"求一个有序任务分配方案满足 SLA 的最小线程池大小"。请用二分答案思路说明：答案区间、单调性、check 函数怎么写、复杂度。（30分）

> 参考答案：
> - 答案空间：线程池大小 x ∈ [1, 上限N]（如最大可承载并发）
> - 单调可行性：x 越大吞吐越高越容易满足 SLA（排队时间达标）→ 一旦 x 可行，更大的都可行 → 可二分
> - check(x)：以 x 并发模拟任务到达与处理（排队/利用率），判断 P99 等待是否 ≤ SLA 阈值，可用利特尔法则 并发≈到达速率×平均耗时 估
> - 二分找最小满足 check 的 x，O(N log N) 或按值域 log
> - 关键：体现"识别答案单调性 → 二分答案 + 贪心/模拟判定"，是二分在架构容量规划里的真实用法
