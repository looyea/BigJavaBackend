# 小测验 · 图的存储、遍历与经典算法

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 求无权图的单源最短路径（最少步数），最合适的算法是？（15分）

- A. DFS
- B. BFS
- C. Dijkstra
- D. Floyd

> 答案：B
> 解析：无权图每步代价相同，BFS 第一次到达某点即为最短跳数；Dijkstra 用于正权带权图，Floyd 用于多源。

### 2. 用 Kahn 算法做拓扑排序，如何判断图里有环？（15分）

- A. 队列曾为空
- B. 最终排出的顶点数少于总顶点数
- C. 存在入度为 0 的点
- D. 某个点出度为 0

> 答案：B
> 解析：环上的点入度永远降不到 0、进不了队列，故若 `order.size() < 顶点数` 说明有环——这正是任务编排/课程表判可行性的核心。

### 3. 【多选】关于图的存储与遍历，正确的有哪些？（20分）

- A. 稀疏图用邻接表更省空间，稠密图或需 O(1) 判边用邻接矩阵
- B. DFS 遍历图时必须用 visited 标记，否则遇到环会无限递归
- C. Dijkstra 可以直接处理含负权边的图
- D. 只判"两点是否连通/几个连通块"且边动态合并时，并查集常比 BFS 更省

> 答案：ABD
> 解析：C 错——Dijkstra 依赖"已定最短路不再变小"，负权会破坏，需用 Bellman-Ford。A/B/D 均正确。

### 4. 判断：树是特殊的图，因此遍历树时不需要 visited 标记。（10分）

- A. 正确
- B. 错误

> 答案：A
> 解析：树无环、父到子单向，正常递归不会回到已访问点，无需 visited；而一般图有环，必须 visited 防止无限循环。

### 5. 填空题：Dijkstra 用 ______ 每次取出当前距离最小的未定点做松弛；无向图的一条边在邻接表中通常存 ______ 次。（10分）

> 答案：优先队列 / 小顶堆 / 堆 / 两 / 2

### 6. 微服务架构里要画"服务 A→B→C 的调用依赖图"，并判断是否存在循环依赖导致启动死锁。请说明你怎么建模、用什么算法、如何定位环。（30分）

> 参考答案：
> - 建模：有向图，顶点=服务、边=调用依赖，用邻接表 `Map<Svc, List<Svc>>`
> - 判环：拓扑排序（Kahn，入度 0 出发删边），若排出顶点数 < 总数 ⇒ 有环
> - 定位环：对剩余"没被排出"的顶点集做 DFS 三色标记（白/灰/黑），回到灰点即找到一条环
> - 影响分析：从某服务出发 BFS/DFS 求可达集 = 它故障会波及的下游；反向图遍历 = 它的上游依赖
> - 关键：把"依赖能否满足/会否死锁"归约为图上的拓扑与可达性问题
