# 小测验 · 排序算法全景与稳定性

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. JDK 对对象数组 `Arrays.sort(T[])` 采用的算法是？（15分）

- A. 双轴快速排序
- B. TimSort（归并 + 插入混合）
- C. 堆排序
- D. 计数排序

> 答案：B
> 解析：对象排序需要稳定性，TimSort 稳定且能利用已有有序 Run，近乎有序逼近 O(n)。基本类型 `int[]` 才走不稳定的双轴快排。

### 2. 朴素快排在什么输入上会退化到接近 O(n²) 甚至栈溢出？（15分）

- A. 完全随机数组
- B. 已排序或全相同，且固定取首/尾元素作 pivot
- C. 逆序数组且每步随机选 pivot
- D. 长度为 2 的数组

> 答案：B
> 解析：固定端点 pivot 时有序数组每次只切掉一个元素，递归深度 n → O(n²) 且爆栈。工程用随机/三数取中 + 三路划分 + 小数组切插入规避。

### 3. 【多选】关于排序稳定性与外部排序，正确的有哪些？（20分）

- A. 稳定性在多关键字排序/需要保持相等键原序时才有意义
- B. 归并排序稳定、最坏 O(n log n)，但需 O(n) 额外空间
- C. 数据超出内存时用"分块内排 + 多路归并（堆）"完成外部排序
- D. 堆排序是稳定排序，适合保护多关键字顺序

> 答案：ABC
> 解析：D 错——堆排序不稳定（父子交换打乱相同键相对顺序），要稳定选归并/TimSort。A/B/C 均为标准结论。

### 4. 判断：基于比较的排序，时间复杂度下界是 Ω(n log n)，任何比较排序都无法突破。（10分）

- A. 正确
- B. 错误

> 答案：A
> 解析：决策树 n! 个叶子 → 至少 log(n!)=Ω(n log n) 次比较。想破下界只能用非比较排序（计数/基数/桶），且要求数据是可分桶的整数/有限值域。

### 5. 填空题：`Arrays.sort(int[])` 用 ______ 排序（不稳定、原地求快）；`Arrays.sort(Object[])` 用 ______ 排序（稳定、利用有序段）。（10分）

> 答案：双轴快排 / DualPivotQuicksort / 快排 / TimSort / 归并

### 6. 金融日终要对 20 亿条流水按"账户 + 时间"排序后做区间聚合，单机内存放不下。请以架构视角设计方案，说明每步用到的算法/结构，以及为什么不能用快排一把梭。（30分）

> 参考答案：
> - 不能全量入内存，快排/Arrays.sort 都要求数据在数组里 → 直接排除一把梭
> - 分块：按内存预算切成若干能装下的块，块内用 TimSort/快排排序（多关键字按 (账户,时间) 用 Comparator）
> - 落盘：每块写成一个有序临时段文件
> - 多路归并：用容量=段数的小顶堆存各段当前头部，弹出最小流式写出、该段补下一个，O(N log k)、内存 O(k)
> - 可并行：块内排序并行（parallelSort/ForkJoin），归并阶段受 IO 限制注意顺序写、用较大缓冲控制读放大
> - 关键：体现外部排序思想 + 堆在多路归并里的作用 + 稳定排序保多关键字序
