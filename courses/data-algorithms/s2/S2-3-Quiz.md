# 小测验 · 堆、优先队列与堆排序

> 本卷共 6 题，混合单选 / 多选 / 判断 / 填空 / 简答，满分 100 分，≥ 60 分过关。

### 1. 堆（优先队列）能保证的性质是？（15分）

- A. 整个序列全局有序
- B. 只保证堆顶是全局极值，兄弟节点之间无序
- C. 中序遍历是升序
- D. 任意父节点都等于孩子均值

> 答案：B
> 解析：堆是部分有序，只守"堆顶最值"。想要全局有序得不断 poll 或再排序；`PriorityQueue.iterator()` 不保证有序。

### 2. 对一个含 n 个元素的无序数组建立堆，最优时间复杂度是？（15分）

- A. O(n log n)
- B. O(n)
- C. O(log n)
- D. O(n²)

> 答案：B
> 解析：自底向上对每个非叶节点做一次下沉，因底层节点多但下沉距离短，级数收敛到 O(n)。逐个 offer 才是 O(n log n)。

### 3. 【多选】关于堆与堆排序，正确的有哪些？（20分）

- A. 堆用数组存储，靠下标 `2i+1 / 2i+2 / (i-1)/2` 换算父子，无需指针
- B. 从 10 亿数中取最大 100 个，用容量 100 的小顶堆可流式处理，O(n log 100)
- C. 堆排序是稳定排序，适合多关键字
- D. 合并 K 个有序链表可用容量 K 的小顶堆做到 O(N log K)

> 答案：ABD
> 解析：C 错——堆排序不稳定（堆顶与末尾交换会打乱相同键的相对顺序）。A/B/D 均正确，B 正是堆最典型的 Top-K 用法。

### 4. 判断：`PriorityQueue` 每次 `poll()` 都按插入顺序返回元素。（10分）

- A. 正确
- B. 错误

> 答案：B
> 解析：poll 按堆序（默认最小优先）返回最值，与插入顺序无关；要按插入顺序得用队列，要按优先级才是堆。

### 5. 填空题：小顶堆的堆顶是 ______ 值；求"数据流的中位数"常用一个大顶堆 + 一个 ______ 分别存较小一半与较大一半。（10分）

> 答案：最小 / 小顶堆

### 6. 电商要做"实时热销榜 Top 10"，数据是持续不断的订单流，且要求能随时看当前前 10。请综合哈希与堆说明方案，并指出纯堆的短板与更好的替代结构。（30分）

> 参考答案：
> - 计数：HashMap/Redis Hash 以商品 ID 为 key O(1) 累加销量
> - 取 Top-10：用容量 10 的小顶堆扫一遍，O(n log 10)、内存 O(10)，可流式
> - 纯堆短板：堆只能整体重建取 Top，无法 O(log n) 更新某商品分值后再有序取前 10（堆不支持按 key 定位）
> - 更好方案：Redis ZSet（有序集合，底层跳表+哈希），`ZINCRBY` O(log n) 更新销量、`ZREVRANGE 0 9` 直接取前 10，兼顾动态更新与有序
> - 关键：堆擅长"一次性 Top-K"，"持续更新的排行榜"要用跳表类可定位有序结构（呼应 s2-4）
