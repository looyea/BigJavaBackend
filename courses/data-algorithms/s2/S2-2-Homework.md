# 课后作业 · 平衡树与红黑树

> 2 题，一题概念推演，一题 TreeMap 实战，附验收标准与参考答案。

## 作业 1：红黑树插入染色推演（50分）

**要求**：依次将 `10, 20, 30, 15, 25` 插入一棵初始为空的 BST 并按升序（模拟退化场景），说明：
1. 若不平衡会退化成什么形状、查找复杂度多少。
2. 红黑树插入时新节点为何先染红、何时需要旋转、哪几种情形只需变色。

**验收标准**：
- 能说清"退化=链表、O(n)"。
- 能答出"染红因红不违反黑高、只可能违反红红不相连；叔叔红→变色上溯，叔叔黑直线/折线→旋转+换色"。

**参考答案要点**：
- 升序插入无平衡机制 → 全挂右孩子的链，查找 O(n)。
- 新节点染红：若染黑会立刻破坏"黑高一致"，染红最多破坏"红红不相连"，修复代价小。
- 叔叔红：父叔染黑、爷爷染红，冲突上移一层（变色不旋转）；折线先旋成直线再按直线情形旋 + 换色。

## 作业 2：用 TreeMap 实现"最近生效配置版本"（50分）

**要求**：配置按 `生效时间戳 → 配置内容` 存储，多次动态上线新版本；给定查询时间 t，返回 t 时刻生效的版本（≤t 的最大时间戳对应值）。用 TreeMap 实现并分析复杂度。

**验收标准**：
- `TreeMap<Long,Config>` + `floorEntry(t)`，查询 O(log n)、上线 O(log n)。
- 能对比"排序数组二分查询 O(log n) 但插入 O(n)"与"哈希无法做 floorEntry"。

**参考答案要点**：
```java
Config at(long t){
    Map.Entry<Long,Config> e = tm.floorEntry(t);
    return e == null ? DEFAULT : e.getValue();  // t 早于所有版本时兜底
}
tm.put(onlineTs, cfg);   // 上线即插入，红黑树自动保持有序
```
- 边界：t 小于最早版本 → floorEntry 返回 null，给默认配置。
- 引申：需要"取最近 N 个版本"用 `subMap` 视图，都是哈希给不了的能力。
