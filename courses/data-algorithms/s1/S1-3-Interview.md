# 面试考点 · 栈、队列与双端队列

> 以追问链组织，覆盖类选型、线程池队列、以及栈/队列作为算法骨架的应用。

## 考点 1：为什么不用 java.util.Stack

**起手**：Java 里怎么实现栈？

**追问链**：
1. `Stack` 有什么问题？→ 继承 `Vector`，方法全 `synchronized`（单线程也付锁开销），还继承了 `get(i)` 等破坏栈封装的方法。
2. 用什么替代？→ `ArrayDeque`，`push/pop/peek`，循环数组更快更省。
3. `ArrayDeque` 能存 null 吗？→ 不能，`peek` 用 null 表示空，存 null 会歧义。

## 考点 2：线程池队列与 BlockingQueue（高频深挖）

**起手**：线程池的工作队列选型注意什么？

**追问链**：
1. 为什么必须用有界队列？→ 无界使 `maximumPoolSize`/拒绝策略失效，任务堆积 OOM、延迟不可控。
2. `Executors.newFixedThreadPool` 的坑？→ 用它默认的无界 `LinkedBlockingQueue`，等于关闭保护；生产应手写 `ThreadPoolExecutor`。
3. `ArrayBlockingQueue` vs `LinkedBlockingQueue`？→ 前者有界数组、单锁 + 两 Condition；后者链表、put/take 两把锁吞吐更高但默认近似无界，要显式设容量。
4. 为什么 LBQ 用两把锁？→ 分离入队/出队临界区，让 produce 与 consume 并发，减少争用。
5. 队满怎么办？→ 拒绝策略：CallerRuns 回压、丢弃、或转存死信/MQ 兜底，别静默丢请求。

## 考点 3：栈/队列作为算法骨架

**起手**：哪些算法离不开栈和队列？

**期望**：
- 栈：括号匹配、表达式求值（双栈）、DFS/回溯、单调栈（下一个更大）、撤销。
- 队列：BFS/层序、滑动窗口（配合单调队列求区间最值）、拓扑排序（Kahn 用队列）、限流的滑动窗口计数。
- 优先队列（堆）：Top-K、Dijkstra、合并 K 个有序序列、调度按优先级出队。

**追问**：层序遍历为什么用队列不用栈？→ 要"先发现的先扩展"按层扩散；用栈会先深后广退化成 DFS。

## 考点 4：设计题——用队列实现栈 / 用栈实现队列

**起手**：只用队列实现栈（或反之）。

**期望**：
- 队列实现栈：入队后把前面的元素轮转到后面，使最新元素到队头，`pop` 即 O(1)；或入队 O(n)、出队 O(1) 两种策略说清一种。
- 栈实现队列：两个栈，`inStack` 入、`outStack` 出，`outStack` 空时才把 `inStack` 整体倒入，均摊 O(1)。
- 能分析均摊复杂度（元素最多被搬运一次）即加分。
