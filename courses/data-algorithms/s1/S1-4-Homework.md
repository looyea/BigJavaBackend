# 课后作业 · 哈希表原理与冲突处理

> 2 题，一题为哈希定桶打基础，一题为工程选型分析，附验收标准与参考答案。

## 作业 1：手写一个链地址法 mini 哈希表（60分）

**要求**：实现 `MyHashMap`，支持 `put(k,v)` / `get(k)` / `size`，用"数组 + 链表"处理冲突，负载因子 0.75，超过则 2 倍扩容并 rehash。

**验收标准**：
- 定桶用 `hash(key) & (cap-1)`，容量保持 2 的幂。
- 扩容后所有元素重新定桶且查找仍正确；`get` 平均 O(1)。

**参考答案要点**：
```java
// 桶: Node[] table; Node{int hash; K k; V v; Node next;}
int idx = (h = hash(key)) & (table.length - 1);
// put: 遍历 table[idx] 链，命中(==hash && equals)则覆盖，否则头插；++size 后判断 size > cap*0.75 → resize()
// resize: newCap=cap<<1; 逐桶 rehash（可借"新增位0/1拆成两条链"优化）
```

## 作业 2：哈希 vs 树 选型分析（40分）

**要求**：为以下需求各选"哈希 / 平衡树 / 都行 / 都不行"，并一句话说明理由：
1. 判断某风控黑名单 ID 是否存在（10 亿级，可容忍极小误判）。
2. 按时间范围查询某账户的流水。
3. 缓存里按 key 精确取商品详情。
4. 取"积分排名前 10"的用户。

**验收标准**：能抓住"是否需要有序/范围/前缀/排名"这条分界线。

**参考答案要点**：
1. 布隆过滤器（哈希家族，省内存容忍假阳性）——精确则 HashSet。
2. 平衡树/有序结构（要按时间范围 → 哈希做不到，需有序，如 DB 的 B+ 树索引 / TreeMap）。
3. 哈希（纯精确点查，O(1) 最优，如 Redis String/HashMap）。
4. 有序结构（排名靠排序/堆/跳表 ZSet，哈希不保序无法排名）。
