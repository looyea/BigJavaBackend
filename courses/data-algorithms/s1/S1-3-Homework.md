# 课后作业 · 栈、队列与双端队列

> 2 题，一题手写栈的应用，一题做队列的容量设计，附验收标准与参考答案。

## 作业 1：用 ArrayDeque 实现括号匹配与表达式求值（60分）

**要求**：
1. 写 `boolean valid(String s)` 判断 `()[]{}` 是否匹配。
2. 进阶：写双栈法计算只含 `+ - * /` 与括号的非负整数表达式，如 `"3+(2*4-6)/2"`。

**验收标准**：
- 用 `ArrayDeque`（不用 `Stack`）；闭括号时弹栈顶配对，不匹配或结束时栈非空返回 false。
- 表达式：数字进操作数栈、运算符按优先级进运算符栈，遇 `)` 弹出计算到 `(`，最终依次算完。

**参考答案要点**：
```java
Deque<Integer> nums = new ArrayDeque<>();
Deque<Character> ops = new ArrayDeque<>();
// 遇数字拼接入 nums；遇 '(' 入 ops；
// 遇运算符：当栈顶优先级 >= 当前，先算一次再入栈
// 遇 ')'：循环弹出计算直到 '('
// 收尾：ops 剩余运算符依次算完，返回 nums.pop()
```

## 作业 2：BFS 层序 + 队列削峰综合分析（40分）

**要求**：
1. 用队列写二叉树层序遍历，说明"为什么这里必须是队列而不是栈"。
2. 一个异步任务线程池 QPS 峰值 2000、单任务 50ms、下游仅 500 TPS，给出你的 `BlockingQueue` 类型、容量与拒绝策略并说明理由。

**验收标准**：
- 层序要"先发现的先扩展"以按层扩散，FIFO 保证同层节点先后顺序 → 用队列；栈会先深后广变成 DFS。
- 队列有界、容量 ≈ 到达速率 × 可容忍排队时间，队满走 CallerRuns 回压或转存 MQ。

**参考答案要点**：
- `Queue<Node> q = new ArrayDeque<>(); q.offer(root); while(!q.isEmpty()){ int sz=q.size(); for(...) 出队并入子层 }`，`sz=q.size()` 是"按层切分"的关键。
- 下游只有 500 TPS，前端必须靠有界队列 + 限流把洪峰削到下游能承受水平；容量按可容忍延迟算（如容忍 2s → 4000），拒绝策略选回压而非静默丢弃。
