# 系统设计答题框架 · 作业题

> 本节作业 3 题：把七段骨架套用到一道真题、录音自查答题节奏、写一份"提问清单"模板。

## 作业 1：用七段骨架完整拆一道题（限时 40 分钟，动手）

选一道经典题（推荐"设计一个 URL 短链服务"或"设计一个秒杀系统"），严格按七段在白板上（或 Markdown）填满，每段落写产出：

```text
例子目的：把抽象框架落成可交付的七块内容
①需求   写 3 条功能 + 3 条非功能(含 P99 与可用性目标) + 主动假设的量级
②估算   写 QPS(读/分峰值)、存储(取 1 年)、带宽 —— 每项标注"由此推出哪个设计"
③API    缩短/跳转/统计 三个接口的入参出参(REST)
④数据   核心表/键结构 + 分片键选择 + 一句话选型理由(SQL 还是 KV 为什么)
⑤架构   客户端→CDN→LB→无状态服务→缓存→分片DB 的一张数据流图
⑥深挖   挑"热点 key(某个链接被疯狂访问)"展开讲透
⑦权衡   列 3 个 trade-off + "量翻 10 倍"的演进改法
```

**验收标准**：七块都有实质内容（不接受空占位）；②里每个估算结论都能追到⑤/⑥里对应的一个组件；⑥深挖部分至少写到"具体算法/存储结构"级别，不停留在"加个缓存"。

## 作业 2：录音/录像自查答题节奏（动手+复盘）

对着镜子或录音，用 5 分钟口头讲一遍作业 1 的①→②，回听并打分：

1. 是否在开口画框前先讲了"我要澄清/假设 X"（若没有，标记为挂科点①）；
2. 每个组件是否都跟了一句"因为估算得到 Y 所以选它"（否则挂科点②只给方案不给取舍）；
3. 是否出现"一口气讲完不打断式自我检查"（系统设计是对话，练习时故意停顿问自己"这里面试官可能问什么"）；
4. 写一段 50 字复盘：我最常犯的是哪个挂科点，下次怎么强制自己规避。

**验收标准**：录音一段 + 三项自查勾选结果 + 50 字复盘（必须点名一个自己真实存在的挂科倾向）。

## 作业 3：产出一份可复用的"开场提问清单"模板（设计）

把你的澄清问题固化成一张随身模板，要求分三组、可 30 秒扫读：

```text
例子目的：一张能带进任何系统设计题的提问卡
功能组:  核心用例? 边缘功能要不做? 读为主还是写为主?
非功能组: 一致性(CP/AP)? 可用性几个9? 延迟预算 P99? 数据合规/地域?
规模组:  DAU/MAU? 每天新增量? 读写比? 峰值倍数? 数据保留多久?
话术:  "我先假设 [量级], 如果不对您打断我" —— 主动给假设比被动等更主导
反例:  一上来问"用 MySQL 还是 Mongo" —— 太早, 选型该从估算自然导出
```

**交付物**：一张三组提问卡（每组 3~4 问）+ 一句"主动给假设"话术模板 + 一条"不该过早问"的反例。

**提示**：这题真正的考点是把"临场发挥"变成"肌肉记忆"——真正熟练的标志是提问框架脱口而出，而不是临场挤牙膏。
